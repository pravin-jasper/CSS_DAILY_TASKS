# Application Form

A simple and beginner-friendly **Application Form** created using **HTML and CSS**.

## 📌 Project Overview

This project contains a basic application form where users can enter their personal details, upload a file, and select a date and time.

## ✨ Features

* First Name input
* Last Name input
* Phone Number input
* Email input with required validation
* File upload option
* Date selection
* Time selection
* Submit button
* Basic CSS styling
* Rounded input fields
* Colored background and buttons

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 📂 Project Structure

```text
Application-Form/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run


1. Open the project folder.

1. Open `index.html` in your web browser.

## 📝 Form Fields

The application form includes:

| Field        | Type   |
| ------------ | ------ |
| First Name   | Text   |
| Last Name    | Text   |
| Phone Number | Number |
| Email ID     | Email  |
| File Upload  | File   |
| Date         | Date   |
| Time         | Time   |

## 🎨 Styling

The form is styled using a separate `style.css` file. It includes:

* Light green background
* Chocolate-colored text
* Rounded input boxes
* Aqua submit button
* Padding and spacing
* Basic border styling
