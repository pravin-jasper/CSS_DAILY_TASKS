# IndusInd Bank Credit Card Form

##  Project Description

This is a beginner-level **HTML and CSS form project** created to practice form elements, input fields, radio buttons, dropdown menus, images, and CSS styling.

The project contains a sample credit card payment form interface with different input fields and a bank account selection option.

>  **Educational Project:** This is only a frontend practice project. It is not an official IndusInd Bank website or payment system. Never enter real credit card, banking, or personal information.

##  Features

* Credit card type selection
* Credit card number field
* Re-enter credit card number field
* Email ID field
* Mobile number field
* Payment amount field
* Bank account dropdown
* Credit card logo images
* Submit button
* Custom CSS styling
* Rounded input fields and button
* Background and text styling

##  Technologies Used

* HTML5
* CSS3

##  Form Details

The form contains the following fields:

| Field                | HTML Element    |
| -------------------- | --------------- |
| Card Type            | Radio Button    |
| Credit Card Number   | Input           |
| Re-enter Card Number | Input           |
| E-mail ID            | Email Input     |
| Mobile Number        | Number Input    |
| Payment Amount       | Number Input    |
| Bank Account         | Select Dropdown |
| Submit               | Button          |
