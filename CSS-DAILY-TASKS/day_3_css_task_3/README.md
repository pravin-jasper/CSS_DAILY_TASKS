# NAB Banking Website

A simple banking website project created using **HTML and CSS**. This project recreates the layout and visual structure of a NAB-style banking homepage, including navigation, promotional banners, banking services, fraud and security information, travel information, online banking, and a footer.

##  Project Structure

```text
project-folder/
│
├── index.html
├── style.css
├── four.jpg
└── README.md
```

##  Features

* Navigation bar with:

  * Home
  * Business
  * Corporate
  * About
  * Help and Support
* Promotional credit card banner
* Home loan refinancing section
* Savings account section
* Business banking section
* Fraud and scam protection section
* Online safety information
* Travel banking section
* Online banking section
* Personal banking tools and information
* Footer with:

  * Quick Links
  * Policies and Terms
  * Social Media Links

##  Technologies Used

* HTML5
* CSS3

##  How to Run


1. Open the project folder.

2. Make sure `index.html` and `style.css` are in the same folder.

3. Open `index.html` in a web browser.

##  Important

The website uses several images hosted from external NAB URLs. An internet connection may be required for those images to display correctly.

The `four.jpg` image is a local image and should be placed in the same directory as `index.html`.

##  Customization

You can modify the website by editing:

### `index.html`

Change the:

* Text
* Images
* Links
* Buttons
* Sections
* Navigation items

### `style.css`

Change the:

* Colors
* Fonts
* Spacing
* Width and height
* Backgrounds
* Layout
* Button styles
* Image sizes

##  Responsive Design

The current project is primarily designed for desktop screen sizes. Media queries can be added to `style.css` to make the website responsive for mobile phones and tablets.

##  Disclaimer

This is a **student/practice frontend project** created for learning HTML and CSS. It is not an official NAB website and should not be used for real banking transactions.
