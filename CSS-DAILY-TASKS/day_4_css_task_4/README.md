# 🍴 Restaurant Menu

A simple **Restaurant Menu** webpage created using **HTML and CSS**.

This project is designed for beginners who are learning the basics of web development.

##  Project Description

**Tasty Bites** is a simple restaurant menu website that displays different food categories, food names, descriptions, and prices.

The project uses basic CSS styling to create a clean and attractive menu layout.

## 🛠️ Technologies Used

* HTML5
* CSS3

##  Features

* Restaurant name and tagline
* Main Course section
* Snacks section
* Drinks section
* Food descriptions
* Food prices
* Simple hover-free beginner layout
* CSS Flexbox
* Rounded corners
* Box shadow
* No JavaScript
* No CSS media queries

##  Project Structure

```text
Restaurant-Menu/
│
├── index.html
├── style.css
└── README.md
```

##  How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The restaurant menu will be displayed.
